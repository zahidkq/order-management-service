 Order Management Service (OMS)

Backend Order Management Service built using Spring Boot.

## Features
- Create and cancel orders
- Order lifecycle management
- Pagination & sorting
- Global exception handling

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
